# Google Form-like Landing Page

A responsive, Google Forms-inspired web form built with HTML and CSS (no JavaScript).
![image](https://github.com/user-attachments/assets/9985db66-c264-44f7-bb22-7c1e251e1e22)

## Features

- Clean, minimalist Google Forms-like design
- Responsive layout that works on mobile and desktop
- Form fields include:
  - Full Name (Text Input)
  - Contact Number (Phone Input)
  - Address (Textarea)
  - Company Name (Text Input)
  - Email Address (Email Input)
  - Department (Dropdown)
  - Gender (Radio Buttons)
- Form validation (using HTML5 required attribute)
- Hover effects on submit button
- Visual feedback for required fields

## Files Structure
form-project/
├── index.html # Main HTML file
├── style.css # Stylesheet
└── README.md # This documentation


## How to Use

1. Clone or download this repository
2. Open `index.html` in any modern web browser
3. Fill out the form and click submit

## Customization

To modify the form:

1. **Change fields**: Edit the form elements in `index.html`
2. **Change styling**: Modify the CSS rules in `style.css`
3. **Change colors**: Update the color variables in the CSS file

## Browser Support

The form should work in all modern browsers including:
- Chrome
- Firefox
- Safari
- Edge
